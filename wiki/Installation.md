# Installation

## Requirements

Caszual MTG 0.8.0 requires:

- Minecraft **26.2**
- Fabric Loader **0.19.3+**
- Fabric API **0.161.0+26.2+**
- Java **25+**
- MTGCard **1.7.0-26.2**

## Install

1. Install Fabric for Minecraft 26.2.
2. Put MTGCard, Fabric API, and `caszual-mtg-0.8.0.jar` in the `mods` folder.
3. Install the same mod versions on the server and on every player client.
4. Restart Minecraft/server.

Remove any old `mtgcompanion-*.jar` and older Caszual MTG jars from the mods folder; install only the new `caszual-mtg-0.8.0.jar`. The mod ID and block/item IDs have changed to `caszual_mtg`, and content placed under the old ID is not migrated. MTGCard itself is still required.

## Creative tab

Caszual MTG places its functional blocks/items into Minecraft's **Functional Blocks** creative tab:

- Community Land Catalogue
- Community Token Catalogue
- Community Card Collection
- Deck Builder
- Card Counter
- MTG Staff
- Custom Deckbox
- Card Hand

See [Recipes](Recipes.md) for survival crafting.
