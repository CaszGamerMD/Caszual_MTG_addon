# Subtype-filtered counter effects

Shared Oracle grammar now composes “put a/NUMBER +1/+1 counters on each SUBTYPE you control” with supported triggers, including lifegain. Citizen V, Helmut Zemo is resolved without name dispatch. The filter uses current battlefield subtypes on resolution and existing counter replacements. It is not a targeting instruction.

Validation: 18 focused tests passed (2 new subtype tests, 9 lifegain watcher tests, 7 counter replacement tests). Unfamiliar Villain, Goblin, Faerie and Squirrel wording is checked, as is rejection of unknown trailing instructions. Behavioral coverage checks controller boundaries, late entry, source departure, and Hardened Scales.

Fresh five-deck import audit: 198 unique unsupported cards, previously 199. No new gauntlet was run for this focused change. This is simulator coverage, not complete Magic rules conformance.
